Muse Gadget — home bridge installer

Flashes the token-less Muse Gadget firmware (ESP-IDF v6.0.3 build) onto an Espressif ESP32-S3-DevKitC-1 (N8R8) over USB, straight from Chrome.

  1. Plug the board into this computer with a USB data cable.
  2. Click Connect below and pick the board's serial port (it shows up as an ESP32-S3 / USB JTAG port).
  3. Choose Install and wait for it to finish — do not unplug mid-flash.

After flashing: pair the board in the Muse app (Settings → Devices, Developer mode on). This build has no SDK token baked in — if pairing asks for one, the token can be sent to the board over its serial console with the line >sdk_token=<your token>.

Requires Chrome or Edge on desktop (Web Serial). Safari/Firefox won't work.
